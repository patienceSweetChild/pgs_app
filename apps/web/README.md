# @pgs/app-web

Deploy target: **purpleguide.study** (student frontend)

```bash
npm run dev:web      # from repo root
npm run build:web
```

Port **3000**. Route bridges in `src/app/` → monolith `src/app/(public)`, `(auth)`, `portal`, `auth`.
